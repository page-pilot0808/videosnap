Quick questions 💬

Will every Facebook link work?

No. Private, restricted, removed, or unsupported videos may not be available. Facebook may also change how video links work.

Can I use it on my phone?

Yes. VideoSnap adapts to mobile screens, tablets, and desktop browsers.

Is there a size limit?

The server currently limits each downloaded file to 500 MB and applies basic request throttling.
